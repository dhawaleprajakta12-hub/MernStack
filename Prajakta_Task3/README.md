# Task 3 - CSS Selectors

This project demonstrates the use of different CSS selectors and styling techniques.

## Concepts Used

- External CSS using `style.css`
- Element selectors
- Class selectors
- ID selectors
- Background colors
- Text colors
- Font size styling
- Different heading styles
- Paragraph styling
- List styling

## Project Files

- `index.html` - Contains the HTML structure and content
- `style.css` - Contains all CSS styling and selectors
- `README.md` - Project documentation

## How to Run

1. Download or clone this repository.
2. Open the `Prajakta_Task3` folder.
3. Open `index.html` in any web browser.
