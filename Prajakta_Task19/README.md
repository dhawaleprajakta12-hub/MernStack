# JS DOM - Service Booking Web App

This project is a simple service booking page made using HTML, CSS and JavaScript.

## What it includes

- Navigation bar with logo, links, username and logout button
- Left section for added services
- Dynamic cart that updates when an item is added or removed
- Total amount calculation
- Booking form with full name, email, phone and password fields
- Right section with service cards, prices, images and Skip/Add buttons
- Booking validation so a service must be selected before booking

## Files

- `index.html` - page structure
- `style.css` - design and responsive layout
- `script.js` - service data, cart logic and form handling

## How to run

Open `index.html` in a browser. An internet connection is needed for the service images because the demo uses image links.
