# JavaScript - Promise-based Divide Function

In this task, I created a JavaScript function called `divide()` that returns a Promise.

The function takes two numbers. It resolves with the division result when the second number is not zero. If the second number is zero, the Promise is rejected with an error message.

The webpage has input fields for testing different values. I also added five sample test cases, including a division-by-zero case.

The result is handled using `.then()` for a successful division and `.catch()` when an error occurs.

## Files

- `index.html` - webpage structure
- `style.css` - basic page styling
- `script.js` - Promise-based division function and test cases

## How to run

Open `index.html` in a web browser and try the buttons or enter your own numbers.
