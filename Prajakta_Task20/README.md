# FreshFold Laundry Services - Task 20

A simple JavaScript laundry services web app made with HTML, CSS and JavaScript.

## Features
- Responsive navigation bar and hero section
- Laundry services with Add Item / Remove Item buttons
- Dynamic cart and total amount
- Booking form with name, email and phone number
- Booking success message
- Newsletter subscription section
- Quality description cards and footer

## Run
Open `index.html` in a browser.

## EmailJS
The booking code contains the place to connect EmailJS. Add your EmailJS service ID, template ID and public key if you want to send real emails. The page works in demo mode without those values.
